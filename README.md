# Harinfood Soundbox Notifikasi

Aplikasi Android yang membacakan notifikasi pembayaran dan notifikasi lain dari aplikasi pilihan dengan TTS (Bahasa Indonesia).

## Fitur
- **Pilih aplikasi** yang notifikasinya dibacakan (misalnya ShopeePay, DANA, aplikasi bank).
- **Nominal pembayaran** dibacakan dalam kata, misalnya "Pembayaran sebesar dua puluh lima ribu rupiah diterima".
- **Sebutkan nama aplikasi**: menambahkan nama aplikasi pengirim, misalnya "..., dari ShopeePay". Bisa dimatikan.
- **Bacakan notifikasi lain**: notifikasi selain pembayaran juga dibacakan, misalnya "Notifikasi dari WhatsApp. ...". Bisa dimatikan.
- **Blokir kata**: notifikasi yang memuat kata di daftar blokir tidak dibacakan.
- **Nada dan MP3 pilihan** sebelum suara TTS, serta volume notifikasi dinaikkan ke 100% saat berbunyi.

## Cara memasang
1. Buat repository baru di GitHub, lalu upload seluruh isi folder ini.
2. Tunggu build di tab Actions selesai, lalu unduh artifact dan pasang APK di HP.
3. Buka aplikasi, tekan **Buka Izin Akses Notifikasi**, dan aktifkan aplikasi ini.
4. Pilih aplikasi yang ingin dibacakan, lalu atur **Pengaturan Notifikasi**.

Pada beberapa HP (Android 13 ke atas), izin akses notifikasi mungkin perlu diaktifkan lewat **Izinkan setelan terbatas** di info aplikasi.
